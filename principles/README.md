# Build Green AI principles

These are the six public principle guides behind Build Green AI.

Read them in order if this is new to you.

Start with determinism. Then move down the stack.

## The six principles

1. [Default to determinism](01-default-to-determinism.md)
2. [Minimum sufficient model](02-minimum-sufficient-model.md)
3. [Audit before automate](03-audit-before-automate.md)
4. [Measure inference cost](04-measure-inference-cost.md)
5. [Local-first where possible](05-local-first-where-possible.md)
6. [Auditable by design](06-auditable-by-design.md)

## How to use these docs

If you are deciding whether a workflow needs a model at all, start here:
- [Default to determinism](01-default-to-determinism.md)

If the workflow still needs inference, go here next:
- [Minimum sufficient model](02-minimum-sufficient-model.md)

If the workflow itself is still fuzzy or bloated, stop and map it first:
- [Audit before automate](03-audit-before-automate.md)

If the workflow already runs and costs money, measure it:
- [Measure inference cost](04-measure-inference-cost.md)

If the workflow may belong on your own hardware, check this:
- [Local-first where possible](05-local-first-where-possible.md)

If the output needs to survive review, compliance, or legal scrutiny, read this:
- [Auditable by design](06-auditable-by-design.md)

## What these docs are for

The principle docs explain the ideas.

If you are not sure which one applies first, read:
- [Principle Routing](../PRINCIPLE-ROUTING.md)

The [`skills/`](../skills/README.md) directory shows how to apply those ideas in repeatable workflows.

If you want the practical workflow first, go there after reading the principle that matches your problem.
